# 부엌 노트

내 레시피를 적어 두고, 요리할 때 **단계마다 ⏱ 를 눌러** 타이머를 켜는 폰용 노트.
광고·로그인·서버가 없다. 레시피는 그 폰 안에만 남는다.

**링크** → https://leixlix-pixel.github.io/recipe-timer/

## 쓰는 법

- **순서에 「10분」「1분 30초」「1.5시간」이라고 쓰면** 그 자리에 ⏱ 버튼이 생긴다.
  「5~6분」은 앞 숫자(5분)로 잰다. 한 단계에 시간이 둘이면 버튼도 둘이다.
- 타이머는 **여러 개를 동시에** 돌린다. 아래 줄에서 +1분 · 멈춤 · 지우기.
- 끝나면 소리·진동이 **끄기를 누를 때까지** 계속된다.
- 요리 화면에 있는 동안 **화면이 꺼지지 않는다.**
- 재료는 눌러서 챙긴 것 지우기, 단계는 눌러서 끝낸 것 표시.
- 재료 줄에 `[양념]` 처럼 대괄호로 쓰면 소제목이 된다.
- 새 레시피 화면의 **「레시피 글 통째로 붙여넣기」** — 블로그·채팅에서 복사한 글을
  「재료」「만드는 법」 제목을 보고 나눠 넣는다.

## 주의

- **폰 화면을 끄면(잠그면) 소리가 안 날 수 있다.** 브라우저는 잠긴 화면에서 소리를 못 낸다.
  그래서 요리 화면에선 화면을 켜 둔다. 다시 켜면 남은 시간은 정확하다(끝나는 시각을 적어 둔다).
- 레시피는 브라우저 저장소에 있다. 폰을 바꾸거나 사이트 데이터를 지우기 전에 **백업 내보내기**.

## 폰에서 앱처럼 쓰기

- **아이폰**: 사파리 → 공유 → `홈 화면에 추가`
- **안드로이드**: 크롬 → ⋮ → `홈 화면에 추가`
